# Genesis - Documento de Requisitos

## 1. Visão Geral

Genesis é um projeto fictício de um estúdio de beleza, desenvolvido inicialmente como uma landing page para apresentação da marca e captação de clientes.

---

## 2. Objetivo

Apresentar o Genesis, seus serviços, equipe e espaço, proporcionando uma experiência visual moderna e minimalista e incentivando potenciais clientes a entrar em contato pelo WhatsApp.

---

## 3. Público-alvo

Pessoas de diferentes faixas etárias que buscam serviços de beleza, autocuidado, renovação da aparência e bem-estar.

---

## 4. Identidade e conceito

Nome: Genesis

Segmento: Estúdio de beleza

Conceito:

Moderno, minimalista, puro e revigorante.

Sensações que a identidade deve transmitir:

- renovação;
- leveza;
- cuidado;
- sofisticação;
- naturalidade;
- bem-estar.

Definição visual:

Utilização predominante de tons claros e rosados, com elementos minimalistas e bastante espaço visual.

## 8. Requisitos funcionais

RF01 — Visualização dos serviços

O usuário deve conseguir visualizar os serviços oferecidos pelo Genesis.

RF02 — Detalhamento dos serviços

O usuário deve conseguir acessar informações detalhadas de cada serviço.

RF03 — Contato via WhatsApp

O usuário deve conseguir entrar em contato com o Genesis através do WhatsApp.

RF04 — Visualização da equipe

O usuário deve conseguir visualizar informações sobre a equipe.

RF05 — Visualização da galeria

O usuário deve conseguir visualizar a galeria de imagens.

RF06 — Consulta ao FAQ

O usuário deve conseguir consultar perguntas frequentes através da seção FAQ.

RF07 — Visualização das informações de contato

O usuário deve conseguir acessar as informações de contato e localização.

---

## 9. Requisitos não funcionais

RNF01 — Responsividade

O site deve funcionar adequadamente em dispositivos desktop, tablet e mobile.

RNF02 — Performance

O site deve priorizar carregamento rápido e otimização das imagens.

RNF03 — Acessibilidade

Elementos interativos devem possuir identificação adequada e o conteúdo deve ser navegável de forma acessível.

RNF04 — Compatibilidade

O site deverá funcionar nos principais navegadores modernos.

## 12. Restrições do projeto

O projeto inicial será desenvolvido exclusivamente como uma aplicação front-end utilizando HTML, CSS e JavaScript.

O sistema de agendamento não fará parte da primeira versão.

O projeto utiliza dados fictícios para fins de portfólio.
