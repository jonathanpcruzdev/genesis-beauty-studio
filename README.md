# Genesis Beauty Studio

## Sobre o projeto

Genesis Beauty Studio é um projeto fictício de um estúdio de beleza.

O projeto tem como objetivo desenvolver uma landing page moderna e minimalista para apresentação da marca, divulgação dos serviços e captação de clientes através do WhatsApp.

---

## Objetivo

O projeto foi desenvolvido como parte de um portfólio de desenvolvimento web, com foco em:

- desenvolvimento front-end;
- responsividade;
- experiência do usuário;
- acessibilidade;
- organização de código;
- boas práticas de desenvolvimento.

---

## Tecnologias

- HTML5
- CSS3
- JavaScript

---

## Funcionalidades

- Apresentação do estúdio;
- Divulgação dos serviços;
- Galeria de imagens;
- Apresentação da equipe;
- FAQ;
- Informações de contato;
- Integração com WhatsApp.
